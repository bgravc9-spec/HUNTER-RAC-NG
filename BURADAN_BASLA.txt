HUNTER RACING - DIREKT GITHUB
===========================

1) HUNTER_RACING_DIREKT_YUKLE.zip dosyasini AC.
2) ZIP icindeki tum dosya/klasorleri GitHub reponun EN UST DIZININE yukle.
   ZIP'te ekstra bir HUNTER_RACING_V1 klasoru YOK.
   app/ web/ tests/ klasorlerini DUZLESTIRME: Android bunlara ihtiyac duyuyor.
3) AYRI verdigimiz android-apk.yml dosyasini su yola koy:
   .github/workflows/android-apk.yml
4) GitHub Actions > HUNTER RACING - APK OLUSTUR > Run workflow.
5) HUNTER-RACING-debug artifact'i -> app-debug.apk.

Not: Bu proje kaynak ZIP'tir, icerisinde derlenmis APK bulunmaz.
